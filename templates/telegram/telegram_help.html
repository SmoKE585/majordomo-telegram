Быстрый старт

Пять шагов до рабочего бота

Настройка занимает несколько минут, если есть доступ к my.telegram.org и HTTPS-домен.

1
Создайте бота

Напишите @BotFather команду /newbot, задайте имя и получите токен вида 123456789:AAHe….

2
Сохраните токен

Откройте Настройки, вставьте токен и нажмите «Сохранить». Затем «Проверить связь» — имя бота и аватар подтянутся автоматически.

3
Добавьте пользователя

Пользователь отправляет боту /start, после чего появляется в списке. Включите нужные права и привяжите его к пользователю MajorDoMo.

4
Создайте команду

Например /ping с кодом return 'Pong!';. Команда появится в клавиатуре, а меню Telegram обновится кнопкой «Меню команд».

5
Запустите приём

Цикл telegram запускается в разделе «Циклы». Альтернатива — webhook: быстрее, но нужен HTTPS-домен.

Сеть

Если Telegram недоступен

Bot API — обычный HTTPS. Выберите способ, который подходит вашей инфраструктуре.

Открыть настройки
HTTP/SOCKS5-проксипросто

Подходит, если есть рабочий прокси. Для Tor: 127.0.0.1:9050, тип SOCKS5 или SOCKS5 + remote DNS.

  • Плюс: настраивается за минуту.
  • Минус: прокси видит токен и трафик; нужен доверенный сервер.
Прозрачный прокси / VPNсистемно

cURL не знает о прокси: маршрут задаёт ОС. Подходит VPN, tun2socks, redsocks, политика маршрутизации или nginx stream со SNI-роутингом.

  • Плюс: не нужно хранить пароль прокси в модуле.
  • Минус: настройка выходит за пределы MajorDoMo, ошибки сложнее диагностировать.
Локальный Bot API (MTProto)надёжно

Рядом с MajorDoMo запускается telegram-bot-api. Он общается с Telegram по MTProto и отдаёт Bot API на 127.0.0.1:8081. PHP ходит на localhost и не зависит от блокировок HTTPS.

  • Плюс: устойчиво к блокировкам, не нужен внешний прокси.
  • Минус: нужен api_id/api_hash с my.telegram.org и запуск отдельного контейнера/сервиса.
Запуск 
[#EXAMPLE_BOT_API#]
MTProto-прокси ≠ Bot API
Ссылки tg://proxy?… описывают MTProto-прокси для клиентов Telegram. Bot API через них напрямую не работает. Используйте локальный Bot API (он сам ходит по MTProto) или прозрачный прокси/VPN.

Команды

Как писать команды

Команда срабатывает после точного совпадения названия или псевдонима; остаток строки приходит в $args.

[#begin COMMAND_EXAMPLES#]
[#TITLE#]

[#DESCRIPTION#]

[#CODE#]
[#end COMMAND_EXAMPLES#]

Переменные в коде команды

$chat_idID чата, куда пришло сообщение
$textПолный текст сообщения
$argsТекст после команды
$commandСработавшая команда
$userЗапись из tlg_user
$telegram_moduleЭкземпляр модуля для отправки сообщений

Диагностика

Частые проблемы

401 Unauthorized

Токен неверен или отозван. Получите новый у @BotFather и пересохраните настройки.

409 Conflict: can't use getUpdates while webhook is active

Настройки webhook и опроса конфликтуют. Нажмите «Снять webhook» или включите режим webhook.

Chat not found

Пользователь не начинал диалог с ботом или chat_id указан с ошибкой. Для канала добавьте бота администратором.

Время ожидания истекло

Проверьте прокси, VPN или локальный Bot API. Увеличьте «Таймаут запроса», если канал медленный.

Кнопки с callback не работают

Включите событие «Нажатие inline-кнопки» или используйте callback_data вида cmd:имя.

Нет уведомлений из системы

У пользователя должен быть включён флаг «Уведомления», а уровень сообщения — не ниже приоритета истории.

Профиль

Чат и имя

chat_id — числовой идентификатор чата. Для групп и каналов он отрицательный.

Пользователь узнает свой ID командой /id или из уведомления «Незарегистрированный пользователь».
Подставляется автоматически при обновлении профиля. Можно задать своё.
Права

Что разрешено

Без прав пользователь не может выполнять команды и получать уведомления.

Уведомления и привязка

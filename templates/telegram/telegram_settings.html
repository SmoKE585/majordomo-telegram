Локальный Bot API — самый устойчивый вариант
Сервер telegram-bot-api запускается рядом с MajorDoMo, общается с Telegram по MTProto и отдаёт обычный Bot API на localhost. В поле «Базовый URL» укажите http://127.0.0.1:8081.
Получите на my.telegram.org/apps.
Нужен только для запуска локального сервера, в запросах Bot API не передаётся.

Доставка

Webhook

Telegram сам присылает обновления на HTTPS-адрес. Быстрее опроса, но требует внешнего HTTPS и домена.

[#if WEBHOOK="1"#]включён[#else#]опрос[#endif#]
Только HTTPS с валидным сертификатом. По умолчанию: [#WEBHOOK_URL_DEFAULT#]. Файл public/webhook_telegram.php должен быть доступен по этому адресу.
Telegram присылает его в заголовке X-Telegram-Bot-Api-Secret-Token; точка входа отклоняет чужие запросы.
Только для самоподписанного сертификата (self-signed).
Сколько соединений держать открытыми. 40 — типовое значение.
